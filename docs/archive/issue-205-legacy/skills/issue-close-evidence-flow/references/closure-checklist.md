# Closure Checklist

- Is the issue actually ready to close?
- Is the closure `code` or `non-code`?
- Is PR URL or commit SHA present when needed?
- Were follow-ups searched in Issue body/comments, merged PR body/comments, Phase D output, and `tasks/issue-*.md`?
- Are explicit follow-up links included when they exist?
- If no explicit follow-up exists, is it written as `なし`?
- If follow-up is only inferred, is the result `BLOCKED` instead of guessed?
- Is milestone audit log required?
- Is repository status vocabulary preserved?
- Is the closure evidence comment ready before the close action?
- Was an empty/silent write response rejected as insufficient evidence?
- Was the posted closure evidence comment confirmed via comment URL/id or read-back before close?
